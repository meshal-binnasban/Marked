we did not—instead we deleted the marks at 1 because of non-termination

The gratifying feature of this definition is in the SEQ-case where the marks
are just shifted from the first regex to the second (similarly in the NTIMEScase). There is no need for a complex case-distinction involving nullable.
The interesting point in the STAR-case is that we are generating a set of
marks by calculating shifts ms r first, but then remove all marks that have
not changed. If this set is empty, the recursion can be exited. Otherwise we
recurse further with only the shortened marks. The result is that, like in the
case of the old shifts, the lexicographic measure consisting of the size of the
regular expression and the maximum string in the marks is smaller in each
case. For example, the regular expressions in the SEQ and NTIMES case
are smaller. In the recursive case of STAR, the second recursive call is only
involving shortened marks. Therefore the measure gets smaller.1

NOT-Regular Expression
There is a problem with the NOT-regular expression and the shifts algorithm. At the moment I have implemented this case shifts ( NOT r ) ms as
1) Take the minimal index in ms and calculate the set of integers from
this minimum up to the end of the string.
2) Subtract from this set of indices all indices calculated by shifts r ms
(since we want to recognise the strings that are not recognised by r).
